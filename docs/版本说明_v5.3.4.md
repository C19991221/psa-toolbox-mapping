## 这个版本多了什么

### 一、新增「按键映射」页 —— 13 行按键都可以自定义启动应用

| 键 | 单击 | 长按 |
| --- | --- | --- |
| 灯杆顶端（仅原功能为唤醒语音助手的车型） | ✅ | ✖（会顶掉原厂长按唤醒语音） |
| 蓝牙电话 | ✅ | ✅ |
| 方向盘语音键 | ✅ | ✅ |
| 空调钢琴键 | ✅ | ✅ |
| 车辆设置钢琴键 | ✅ | ✅ |
| 蓝牙电话钢琴键 | ✅ | ✅ |
| 手机互联钢琴键 | ✅ | ✅ |
| SRC 切源键 | ✅ | ✖ |
| 音乐键 | ✅（仍归工具箱） | ✅（新增） |
| 地图键 | ✅（仍归工具箱） | ✅（新增） |
| 会员中心键（508 系有该键码） | ✅ | ✖ |
| 车机设置键（508 系有该键码） | ✅ | ✖ |
| LIST 键 | 开关 360 全景 | ✖ |

- 选应用是**网格挑选**，第一格「无」＝恢复原厂行为。
- 系统里那些不该给用户点的应用（MultiScreen、Uwrite、CarTrustAgent、AutomateTest、执行引擎、语音助手、theme.style1）**已过滤**。
- **不支持长按的键，界面上就不会显示长按格** —— 不会给你一个按了没反应的按钮。

### 二、新增「应用管理」页

列出车机自带的关键应用和已装第三方应用，**点一行才展开**「清缓存 / 清数据 / 卸载（更新）」。顶部还有「扫码上传 APK」，用手机扫码就能往车机装 APK。

### 三、屏蔽「车机未连接到服务器，请重试」弹窗

4G 没信号或车机没激活时，公共服务会反复弹这个框。这版直接把它关掉了。

### 四、音乐键 / 地图键的长按，改为由注入层统一接管

原来这两个键的长按走的是另一条通道，版本升级/重装容易失效。现在并入注入载荷，跟其他键一致。

### 五、界面重做

- 菜单分组：系统设置…仪表投屏 ／ 油耗账本 ／ 应用管理·维护诊断·专家模式 ／ 关于软件，组间有细线。
- 四级字号统一（页面标题 28 / 分组 21 / 条目 18 / 说明 14sp）。
- 修了滑动掉帧：大面积阴影改成独立静态层，不再跟着列表重绘。
- 「检查更新」搬到关于软件页，贴在版本号右边。
- 缓存清理并入存储清理，不再有两处都在清同一个 `/sdcard`。
- 内存清理的名单改成左右两栏勾选，能直接选应用，不再手打包名。
- 工程模式入口挪到专家模式最底部，没解锁时完全不显示。
- 在线更新走 GitHub 直链，不用再配服务器。

## 安装

**必须是车机**（包里有 `sharedUserId=android.uid.system`，手机装不上）。

```powershell
adb connect <车机IP>:5555
adb install -r psa-toolbox_一体版_release.apk
```

装完打开，进「维护诊断」→ 最下面「工具箱」→「修复PSA工具箱」→「立即修复」。

> 这一步是把按键映射的补丁注入到车机的公共服务（`com.cusc.misc`）里。
> **注入前建议先用工具箱的「卸载更新」把公共服务退回原厂**，避免叠加上一版的补丁。
> 注入完建议重启一次车机。

## 实测情况（2026-11-16，408 / 3VS121 / Android 9）

已验证通过：

- 安装、启动、11 个页面全部正常，无崩溃
- **物理按键实测**：灯杆顶端单击 → 启动设置；方向盘语音键／空调键未配置时正确回落原厂
- **音乐键、地图键长按实测生效**（日志里是 `onKeyLongClick` 分支，不是短按分支）
- 属性写入正常（`persist.bandwa.*` 能被系统 uid 写入）
- 注入完整：9 个按键属性名、`psaHandle`／`psaLaunch`／`psaBoot`／`stopAVMDisplay` 全部在包里
- **弹窗屏蔽确认**：反编译实车包，`Data4gImpl.showNetState()` 第一条指令就是 `return-void`
- 在线更新：车机能直连 GitHub（105ms），手机端点「检查更新」能取到远端版本信息

**没验的**（如实说）：

- 只测了 408，508／4008／5008／天逸 没测
- 360 开关是车主自己测的，没留日志
- 没做过断电冷启动，开机那三件事没验
- 完整升级流程（下载→安装→变新版）没跑，只验到「能取到远端内容」

## 已知问题

1. **雪铁龙版 HiCar 修复**：车上没有这个包，按钮已隐藏。
2. **多媒体插件安装**：暂时没有可用的修复版，按钮已隐藏。
